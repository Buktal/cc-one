# cc one

> **あなたの AI CLI 使用量は、あなたのもの。** cc one は AI CLI がすでに書き出しているセッションログを読み取り、トークン・コスト・キャッシュ効率・トレンドに変換します。ローカルファーストのデスクトップダッシュボードで、自分が管理する GitHub リポジトリ経由の複数端末間同期もオプションで利用できます。

## 問題

AI CLI——**Claude Code、Codex、Gemini CLI、Grok CLI、OpenCode**——を使うたびに、セッションログがディスクに書き出されます。入力トークン、出力トークン、キャッシュのヒットとミス、支出額——それらすべてはプレーンテキストとして端末に残されたままです。cc one はそのログを読み取り、**いくら使ったか、何を得たか、トークンがどこへ向かったか**を鮮明な形にします。

そして AI CLI を切り替えるとき——その背後でプロバイダーを切り替えるとき——cc one はそれも代行し、各 CLI が実際に読み込む設定ファイルを書き込みます。

製品全体は 2 つの姿勢で形作られています：

- **ローカルファースト。** フル機能のダッシュボードはゼロネットワークで動作します。ログはすでにあなたのディスクにある——それだけで十分です。
- **ログに対して厳密に読み取り専用。** cc one はセッションログを*読むだけ*です。ログを変更せず、ツールの動作にも一切触れません——ツールはこれまで通り動き続けます。唯一の例外はプロバイダーの切り替えで、これは CLI が読み込む設定を書き込みますが、常にあなたの明示的な操作であり、書き込み前にバックアップされます。

複数端末間同期は純粋に **opt-in** の追加レイヤーであり、利用の前提条件ではありません。

## 機能

### プロバイダー

- **5 つの AI CLI、1 つの設定ハブ** —— Claude Code・Codex・Gemini CLI・Grok CLI・OpenCode がそれぞれのプロバイダーリストを持ちます：名前・カテゴリ・エンドポイント・認証。切り替えはその CLI が*実際に読み込む*設定ファイルを書き込みます——Codex の `config.toml` + `auth.json`、Gemini CLI の `settings.json` + env、Grok の `config.toml`、OpenCode の `opencode.json`——制御フィールドのみをマージし、書き込み前には必ずバックアップを取ります。
- **59 のビルトインプリセット、5 プール** —— 各 CLI 専用のプールを用意：Claude Code 18（公式 + AWS Bedrock、国内ベンダー 11 社、人気アグリゲーター 4 社）、Codex 17、OpenCode 12、Gemini CLI 6、Grok CLI 6。プリセットを選択し、キーを入力して切り替えます。
- **生の設定エディター** —— 各プロバイダーは完全な settings スナップショットを保持します。内蔵 JSON エディターが全体を表示し、オンデマンドでフォーマットし、パースエラーを静かに破棄せず警告します。
- **モデルロールマッピング** —— 5 ロール（Sonnet / Opus / Fable / Haiku / Subagent）、それぞれにモデルと 1M コンテキストトグル。ワンクリックでベンダーのモデルリストを取得、「すべてに適用」で 1 つのモデルを全ロールへ展開。
- **どこからでもインポート** —— CC-Switch のエクスポート、ローカル設定ファイル、CC One バックアップの 3 ソースを対等に扱い、opencode.json インポートは適用前に変更をプレビュー。リスト全体はいつでも JSON でエクスポート可能。
- **構造は同期、キーは同期しない** —— プロバイダーリストは同期リポジトリを経由して端末単位でバイト安定同期。端末の外へ出るものからは常に API キーが除去されます。

### ダッシュボード

- **4 バケットのトークン経済** —— input / output / cache creation / cache read。各 CLI のネイティブなセマンティクス（例：Codex のキャッシュ込み input）を、請求書に一致する 1 つのモデルに正規化します。
- **キャッシュヒット率** —— `cache_read / (input + cache_creation + cache_read)`。上流の使用量集計方法に合わせています。
- **token 優先のモデル分布** —— 使用量の内訳はトークン順でモデルを並べ、それぞれにキャッシュヒット率を表示。
- **リクエスト数とコスト** —— 総リクエスト数と総コスト（USD）、収集時点で固定。
- **使用量トレンド** —— メトリックごとに 1 系列の多系列トークン対コストチャート。今日と昨日の差分も表示。
- **呼び出し単位のリクエストログ** —— ソース・モデル・トークン内訳・コスト・ターン所要時間、`stop_reason` / `service_tier` チップ。行をクリックすると完全な詳細を展開。
- **ターン単位ビュー** —— ターン全体のコストと実経過時間を、単発呼び出しのタイミングとは別に表示。

### セッション

- **すべての会話をブラウズできる履歴** —— AI CLI が実行したすべてのセッションをプロジェクトディレクトリ配下に整理し、タイトルとパスの全文検索に対応。期間・ソース・モデル・デバイスでフィルタ可能。
- **完全なトランスクリプトが即座に閲覧可能** —— 各セッションの会話は収集時にローカルデータベースへ書き込まれるため、お気に入り登録の有無に関係なく、どのセッションもロール別に色分けされた完全なトランスクリプトを開けます。書き込み中のログファイルを再読取することはありません。
- **トランスクリプトがマークダウンで描画** —— コードブロックと JSON はシンタックスハイライト付きでテーマに追従。Claude Code のサブエージェント実行はエージェントタイプバッジ付きの独立セッションとして表示されます。
- **セッション内の検索とジャンプ** —— トランスクリプト全体でヒットをハイライトし、隣の番号付きターンパネルからターゲットメッセージへ直接ジャンプ。
- **2 タブ、2 通りの整理方法** —— **ローカル** タブはこの端末で収集したすべてを、決して端末の外に出ないプライベートグループに整理。**お気に入り** タブは全端末でスターを付けたセッションを、同期グループに整理して表示し、各エントリにソースデバイスを付記します。
- **お気に入りの端末間同期** —— 一度スターを付けると、そのトランスクリプトは同期リポジトリ経由で他のすべての端末へ配信されます。スターを外せば、すべての端末から削除されます。端末の外に出るのはお気に入り登録したセッションだけです。
- **セッション単位の経済** —— 各セッションのリクエスト数・トークン内訳・コストは使用量レコードからのライブ集計で表示——二重保存は一切ありません。

### 同期（オプション）

- **スタンドアロンまたは同期モード** —— 完全オフラインで運用するか、自分が管理する GitHub リポジトリをバインドして端末間でデータを揃えます。
- **自分のリポジトリ、プレーンテキストの成果物** —— 使用量は人間が読める、端末別・日付別の JSONL（`data/<device>/usage-YYYY-MM-DD.jsonl`）として、あなたが管理するリポジトリへ投影されます。間にサードパーティのサーバーはありません。
- **端末分離・無衝突** —— 各端末は自分の `data/<device>/` サブツリーにだけ書き込むため、同時 push が衝突することはありません。push 競争に負けた端末は、次の同期でローカルコミットをリモートの先端に rebase して自己修復します。
- **決定的な成果物** —— 収集はローカルストアだけに書き込みます。push は変更された各日の成果物をストアからバイト単位で再生成するため、2 台の端末が同一ファイルの内容について食い違うことはあり得ません。
- **システムプロキシ対応** —— push/fetch は OS のプロキシ（Clash/Mihomo、企業ゲートウェイ）に従うため、同期モードはその背後でもそのまま動作します。
- **端末単位のビュー** —— ダッシュボード・グランスカード・ミニバーを単一端末に絞り込み。ピアの忘却もローカルで行え、失われたピアは自動的にクリアされます。

### ライブラリ

- **ドラッグで中継アップロード** —— ファイル / ディレクトリをウィンドウにドロップすると、同期リポジトリ経由でその端末のサブツリーへ push。任意の深さのネストディレクトリに対応。
- **アプリ内プレビュー** —— 画像は幅フィット + ctrl+ホイールでズーム。テキストと JSON はテーマ対応でプリティプリント。それ以外はサンドボックス iframe で表示。
- **手動エクスポート** —— エントリを自分で選んだパスへ保存。cc one は対象パスを知らず、AI ツール自身の設定ディレクトリにも一切書き込みません。
- **安全な上書き** —— 同名同種は上書き（git 履歴が安全網）、同名異種は拒否。
- **端末別・ゼロ衝突** —— 各端末は自分のサブツリーを持ちます。ピアの忘却時には、そのファイルを `from-<peer>/` 配下へ移行するか削除するかを選択できます。

### コストと価格

- **モデル別に価格を編集可能** —— シード価格を上書きし、cc one はあなたの数値を使います。
- **LiteLLM から取得** —— ワンクリックで最新のモデルコスト表を取得。
- **Rebill（再請求）** —— 収集時に価格のなかったレコードを、既存履歴を再計算せずにバックフィル。
- **価格表の持ち運び** —— 価格表を JSON でインポート / エクスポート。

### エクスペリエンス

- **軽量グランスモード** —— 画面端に今日の合計を常時表示するミニバーをタックするか、ダッシュボードを映すフローティングカードへ展開。full ⇄ expanded ⇄ tucked の 3 形態を切り替えでき、各形態の配置は個別に保持されます。
- **マルチスキンテーマ** —— 5 つのアクセントカラーとチャートパレット（Neutral / Sage / Azure / Crimson / Mauve）。コンテンツに触れずアプリ全体を再配色。ダークモードではページ・モーダル・入力欄の 3 段階のサーフェス階層が奥行きを読みやすくします。
- **トレイ常駐のバックグラウンド収集** —— 増分スキャナが 5〜60 秒間隔でダッシュボードを最新に保ちます。ウィンドウは不要。
- **自動更新と 3 言語** —— 署名付き更新を GitHub Releases から直接インストール。UI は English・简体中文・日本語に対応。

## ローカルに留まるもの、同期されるもの

| | スタンドアロン | 同期モード（リポジトリバインド済み） |
| --- | --- | --- |
| 使用量・コスト・トレンド・リクエストログ | ローカルのみ | 端末間で同期 |
| セッションのトランスクリプトとお気に入り | ローカルのみ | お気に入り登録したセッションのみ同期、他はローカル |
| プロバイダー構造 | ローカルのみ | 端末単位で同期——API キーは決して同期されない |
| ライブラリファイル | ローカルのみ | 端末間で同期 |
| 設定・スキン・価格上書き・ローカルグループ | ローカル | ローカル——リポジトリには一切書き込まれません |

リポジトリをバインドして同期を有効にしない限り、データが端末の外へ出ることはありません。使用するアクセストークンも端末に留まり、リポジトリに書き込まれることはありません。

## 仕組み

```
  AI CLI セッションログ
  (Claude Code · Codex · Gemini CLI · Grok CLI · OpenCode)
          │  (読み取り専用)
          ▼
       Collect ──────▶ ローカルストア (SQLite) ──────▶ ダッシュボード & セッション
          │
          │  (オプション · 同期モード)
          ▼
     成果物 (プレーンテキスト、端末別 + 日付別)
          │
    push / pull は自分の GitHub リポジトリ経由
          │
          ▼
       他の端末
```

[Tauri 2](https://tauri.app/) アプリです：Rust バックエンドが収集・ローカルストア・プロバイダー設定の書き込み・オプションの Git リポジトリ同期を担当し、React フロントエンドが生成された型安全な IPC バインディングを通じてダッシュボードを描画します。コレクターはプラグイン型のプロバイダモデル（Claude Code・Codex・Gemini CLI・Grok CLI・OpenCode）、ローカルストアが唯一の真実の源、同期はそのストアをプレーンテキスト成果物へ投影する opt-in レイヤーです。

| OS | インストーラ |
| --- | --- |

| **Linux** | `.deb`、`.AppImage`（一部で `.rpm`） |

**初回起動：** cc one を起動すると、ローカルの AI CLI セッションログをスキャンしてダッシュボードが自動的に表示されます。アカウントもサインインもネットワークも不要。複数端末で使用量を見たい場合は、**設定**で同期を有効にし、自分が管理する GitHub リポジトリを指定してください。

> **macOS の注意：** 現在のビルドは未署名です。初回起動時はアプリを右クリック → **開く**、または隔離属性を除去してください：
> ```bash
> xattr -dr com.apple.quarantine /Applications/cc one.app
> ```

## ソースからビルド

**前提条件：** [Node.js](https://nodejs.org/) 20+ LTS + [Yarn 4](https://yarnpkg.com/)（[Corepack](https://nodejs.org/api/corepack.html) 経由）、および安定版 [Rust](https://www.rust-lang.org/) とお使いの OS の [Tauri 前提条件](https://tauri.app/start/prerequisites/)。

```bash
corepack enable  # package.json で固定された Yarn バージョンを有効化
yarn install     # 依存関係をインストール
yarn dev         # 開発モードでデスクトップアプリを実行
yarn dist        # リリースバイナリをビルド
yarn check       # 静的チェック（Biome + tsc + Rust fmt/clippy）——CI と同じゲート
yarn test        # テストスイートを実行
```

**技術スタック：** [Tauri 2](https://tauri.app/) (Rust) · [React 19](https://react.dev/) · [TypeScript](https://www.typescriptlang.org/) · [Vite](https://vite.dev/) · [Tailwind CSS v4](https://tailwindcss.com/) · [shadcn/ui](https://ui.shadcn.com/) · [Redux Toolkit](https://redux-toolkit.js.org/) · [Recharts](https://recharts.org/)

## よくある質問

**「cc one（归一）」という名前の由来は？** —— "cc" は Claude Code エコシステム（cc-switch、cc-connect の仲間）に連なる印で、"one" はすべての AI CLI の使用量・設定・同期・将来のエージェント橋渡しを、あなたの手元の一つのツールに収束させるハブです。中国語名は「归一（きいち）」。旧名は VaultOne でした。

**cc one はデータを外部へ送信しますか？** いいえ。すべてローカルログから読み取り、ローカルに保存します。データが端末の外へ出る唯一の経路は同期への opt-in であり、その場合も行き先は*あなたが管理する* GitHub リポジトリ、形式はプレーンテキストです。

**API キーやプロキシは必要ですか？** いいえ。cc one は AI CLI がすでに書き出したログファイルを解析するだけで、モデルプロバイダーへ呼び出しを行いません。

**ログを変更しますか？** 絶対にしません。cc one はセッションログに対して厳密に読み取り専用です。プロバイダーの切り替えだけが設定ファイルを書き込む唯一の操作であり——常にあなたの明示的なクリックで、常にバックアップ後に実行されます。

**対応している AI CLI は？** Claude Code・Codex・Gemini CLI・Grok CLI・OpenCode——それぞれネイティブなログ形式（JSONL・JSON・SQLite）から解析し、トークンのセマンティクスを 1 つのモデルに正規化します。

**なぜ同期に GitHub リポジトリを使うのですか？** あなたがすでに持っているから、無料だから、そしてデータを自分の手元に置けるからです——プレーンテキストの成果物はあなたが管理するリポジトリに置かれ、サードパーティサービスを挟みません。端末分離と自己修復 rebase により、複数端末の同時同期も無衝突を保ちます。
